# Contributing to Docker Lab

Thank you for your interest in contributing! This repo is open to everyone — whether you want to fix a typo, improve explanations, or add new content.

## How to Contribute

1. Fork the repository
2. Create a new branch
```bash
git checkout -b improve/module-name
```
3. Make your changes
4. Commit with a clear message
```bash
git commit -m "improve: description of your change"
```
5. Push to your fork
```bash
git push origin improve/module-name
```
6. Open a Pull Request on GitHub

## Guidelines

- Keep changes focused — one improvement per PR
- If adding a new module, follow the existing README structure
- Include screenshots where relevant
- Test all commands before submitting

## Reporting Issues

Found a bug or outdated command? Open an issue on GitHub with:
- Which module is affected
- What the error is
- Your OS and Docker version
